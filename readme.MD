# C Number Guessing Game 

A feature-rich command-line number guessing game written in C. 
This project was built as part of my early learning journey in C programming.

## Features 

* **Customizable Intervals:** Choose your own minimum and maximum bounds for the secret number.
* **Attempt Control:** Set your preferred number of attempts before playing.
* **Robust Input Handling:** Includes input validation and buffer clearing (`getchar`/`scanf`) to prevent infinite loops when invalid characters are entered.
* **Interactive Menu:** Clean loop-based menu to easily navigate between settings, gameplay, and quitting.

## Getting Started 

### Prerequisites

You need a C compiler installed on your system (like `gcc`).

### Compilation & Execution

Clone the repository and compile the source file using your terminal:

```bash
gcc main.c -o number_game
```
or you can directly run the executable:


linux /macos :```./number_game.exe```
windows : ```number_game.exe```
